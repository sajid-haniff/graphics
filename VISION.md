# Personal Computer Science Canon

## Purpose

This repository exists to systematically reconstruct and deepen my understanding of computer science, mathematics, graphics, algorithms, systems engineering, and software architecture through implementation.

The goal is not to build products.
The goal is to build understanding.

## Core Philosophy

AI should increase agency, not replace understanding.

The repository is a long-term laboratory for:

- Graphics and rendering
- Computational geometry
- Algorithms and data structures
- Artificial intelligence
- Physics simulation
- Compilers and language implementation
- Networking and systems programming
- Operating systems concepts
- Software architecture
- Applied mathematics

Every topic should be approached from first principles whenever practical.

## Learning Model

Mathematics
    ↓
Algorithm
    ↓
Implementation
    ↓
Visualization
    ↓
Engineering Insight

## AI Collaboration

AI is used to reduce mechanical effort:

- implementation scaffolding
- repetitive coding
- boilerplate
- refactoring assistance
- documentation generation

Human effort is focused on:

- architecture
- reasoning
- design tradeoffs
- correctness
- abstraction quality
- review

## Long-Term Goal

Build a personal computer science canon containing:

- implementations
- demos
- documentation
- SVG explanations
- engineering notes

for every major topic explored.
